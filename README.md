# Casting Defect Detection Using Transfer Learning

## Overview

Quality inspection is a critical part of manufacturing processes. Manual inspection of casting products is time-consuming and prone to human error.

This project develops an automated defect detection system using transfer learning and convolutional neural networks (CNNs) to classify casting products as defective or non-defective from industrial images.

The objective is to improve inspection efficiency and support Industry 4.0 manufacturing practices.
